# مشروع متتبع المصاريف

موقع بسيط لإضافة المصاريف وعرض مجموعها ومعرفة المبلغ المصروف على كل فئة.

## أعضاء الفريق

| الاسم | الدور | المسؤولية |
| --- | --- | --- |
| جنى | A | الواجهة والتنسيق وشريط التنقل وملف README |
| وائل | B | الاتصال بقاعدة البيانات وعرض المصاريف وإضافتها |
| مريم | C | قاعدة البيانات وملخص المصاريف والتحقق باستخدام JavaScript |

## التقنيات المستخدمة

HTML، CSS، Bootstrap، JavaScript، PHP، MySQL.

## صفحات الموقع

- **الرئيسية:** عرض المصاريف والمجموع الكلي.
- **إضافة مصروف:** إدخال الوصف والمبلغ والفئة والتاريخ.
- **الملخص:** عرض مجموع المصاريف لكل فئة ونسبتها من المجموع.

## طريقة التشغيل

1. نزّل المشروع باستخدام GitHub Desktop داخل مجلد `www` في WAMP، ليصبح مساره:

   ```text
   C:\wamp64\www\expense-tracker
   ```

2. شغّل WAMP وتأكد أن الأيقونة خضراء.
3. افتح phpMyAdmin واستورد ملف `database/schema.sql` لإنشاء قاعدة البيانات والجداول. إذا طلب منك اختيار قاعدة بيانات، أنشئ قاعدة باسم `expense_tracker` واختَرها ثم استورد الملف.
4. انسخ ملف `config.example.php` وسمِّ النسخة `config.php` في نفس المجلد.
5. عدّل بيانات الاتصال في `config.php` حسب إعدادات جهازك. الإعدادات المحلية المعتادة هي:

   | الإعداد | القيمة |
   | --- | --- |
   | `DB_HOST` | `localhost` |
   | `DB_NAME` | `expense_tracker` |
   | `DB_USER` | `root` |
   | `DB_PASS` | فارغة إذا لم تضع كلمة مرور |

6. افتح الموقع من المتصفح على الرابط:

   ```text
   http://localhost/expense-tracker/public/
   ```

## ملاحظات

- كل عضو ينشئ ملف `config.php` على جهازه، ولا يُرفع هذا الملف إلى GitHub.
- وصف المصروف لازم يكون غير فارغ، والمبلغ أكبر من صفر.
- واجهة الموقع بالإنجليزي، ولا يوجد تسجيل دخول.
- لتجربة الموقع، أضف مصروفًا وتأكد أنه يظهر في الرئيسية وينحسب في الملخص.
